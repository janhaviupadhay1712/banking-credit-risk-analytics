# Resume Content

## 3-Line Resume Project Description

Built an end-to-end Banking Credit Risk Analytics project analyzing 21,500+
loan records using SQL, Python and Power BI to identify default drivers and
segment customers by risk. Designed a transparent rule-based risk scorecard
(Credit Score, DTI, prior defaults, late payments) and a 3-page Power BI
dashboard surfacing an 8.75% NPA ratio and region/loan-type risk concentration.
Delivered 25 SQL queries, 16+ Python visualizations, a formula-driven Excel
workbook, and management-ready recommendations to reduce default exposure.

## 5 ATS-Friendly Resume Bullets

- Analyzed a 21,500+ record loan portfolio using **SQL** (joins, CTEs, window
  functions, subqueries) and **Python** (Pandas, NumPy) to calculate default
  rate, delinquency rate, and NPA ratio, identifying an 8.75% NPA ratio
  concentrated in specific regions and loan types.
- Designed and implemented a rule-based **credit risk segmentation model**
  (Low/Medium/High) using Credit Score, DTI, prior defaults, and late payment
  history, classifying 19.2% of the portfolio as high-risk exposure.
- Built a 3-page **Power BI** dashboard with 15+ DAX measures, KPI cards,
  slicers, and a drill-through high-risk customer watchlist for credit risk
  management stakeholders.
- Automated data cleaning of 21,800+ raw records with **Pandas** (handling
  missing values, duplicates, outliers, inconsistent categorical entries),
  improving downstream analysis reliability by removing 100% of nulls.
- Developed a formula-driven **Excel** workbook (SUMIFS, COUNTIFS, INDEX/MATCH,
  conditional formatting) enabling real-time customer risk lookups and KPI
  tracking for non-technical stakeholders.
