# LinkedIn Project Post

**🏦 Banking Credit Risk Analytics — End-to-End Data Analyst Project**

I built a complete credit risk analytics project to simulate how a bank's
risk/analytics team would analyze its loan portfolio — from raw, messy data
all the way to a management-ready dashboard.

**What it covers:**
📊 Analyzed 21,500+ loan records across 19 attributes (income, credit score,
DTI, employment, region, delinquency history, etc.)

🧹 **Python (Pandas/NumPy):** cleaned real-world messiness — missing values,
duplicate records, inconsistent category text, mixed date formats, and
outliers — then engineered features like Loan-to-Income ratio, EMI estimate,
and credit score bands.

🎯 **Risk Segmentation:** designed a transparent, rule-based scorecard
(Credit Score + DTI + Previous Defaults + Late Payments) to classify every
customer as Low / Medium / High risk — implemented identically in Python and
SQL so the numbers always match.

🗄️ **SQL:** wrote 25 queries covering joins, CTEs, window functions
(RANK, NTILE, LAG), subqueries, and CASE logic to answer real risk
questions — default rate by region/loan type, month-over-month trend,
top-risk customers, branch performance.

📈 **Power BI:** designed a 3-page dashboard (Executive Overview, Credit Risk
Analysis, Loan/Customer Insights) with 15+ DAX measures, KPI cards, slicers,
and a drill-through high-risk customer watchlist.

📑 **Excel:** built a formula-driven workbook (SUMIFS, COUNTIFS, INDEX/MATCH,
conditional formatting) so non-technical stakeholders can look up any
customer's risk profile instantly.

🤖 **Bonus:** a small optional Logistic Regression / Random Forest default
model — kept intentionally secondary to the core analytics work.

**Key finding:** the portfolio's overall default rate is 5.3%, but the
high-risk segment (19.2% of customers by count) holds a disproportionate
share of outstanding exposure — a clear signal for where collections and
underwriting attention should focus.
